# Interactive Websites for Learning About AI

Based on a screenshot of a curated list of ML and deep learning visualization resources, grouped by topic, with a few beginner-friendly additions at the end.

---

## Machine Learning and Statistics Basics

| Resource | Link | Description |
|---|---|---|
| Interactive Machine Learning | https://mlu-explain.github.io | Likely match: Amazon's MLU-Explain, with interactive visual essays on core ML concepts. The name is ambiguous, so verify against your source. |
| A Visual Introduction to Machine Learning (R2D3) | http://www.r2d3.us/visual-intro-to-machine-learning-part-1/ | Explains decision trees through a scroll-driven visual story. |
| Seeing Theory | https://seeing-theory.brown.edu | Brown University's interactive introduction to probability and statistics. |
| ML Visualized | https://ml-visualized.com | Shows the math behind common ML algorithms with visualizations. |

## Neural Networks and CNNs

| Resource | Link | Description |
|---|---|---|
| CNN Explainer | https://poloclub.github.io/cnn-explainer/ | Explore how a convolutional network classifies images, layer by layer. |
| Feature Visualization (Distill) | https://distill.pub/2017/feature-visualization/ | Shows what individual neurons in vision networks respond to. |
| Activation Atlas (Distill) | https://distill.pub/2019/activation-atlas/ | Maps the concepts an image classifier has learned. |

## Transformers and LLMs

| Resource | Link | Description |
|---|---|---|
| Transformer Explainer | https://poloclub.github.io/transformer-explainer/ | Runs a live GPT-2 in the browser so you can watch each step of text generation. |
| LLM Visualization | https://bbycroft.net/llm | 3D walkthrough of every computation inside a small GPT model. |
| The Illustrated Transformer | https://jalammar.github.io/illustrated-transformer/ | Widely used illustrated explanation of the attention mechanism. |
| Transformer Circuits | https://transformer-circuits.pub | Anthropic's interpretability research. More advanced than the others. |

## Generative Models

| Resource | Link | Description |
|---|---|---|
| GAN Lab | https://poloclub.github.io/ganlab/ | Train a generative adversarial network interactively in the browser. |
| Diffusion Explainer | https://poloclub.github.io/diffusion-explainer/ | Shows how Stable Diffusion turns a text prompt into an image. |
| The Illustrated Stable Diffusion | https://jalammar.github.io/illustrated-stable-diffusion/ | Visual breakdown of the diffusion architecture. |

## Specific Concepts (Distill)

| Resource | Link | Description |
|---|---|---|
| How to Use t-SNE Effectively | https://distill.pub/2016/misread-tsne/ | Interactive examples of how t-SNE plots can mislead. |
| Why Momentum Really Works | https://distill.pub/2017/momentum/ | Explains the momentum optimization method with interactive demos. |

## Suggested Use for Teaching

- **Good starting set for AI literacy:** TensorFlow Playground, Teachable Machine, R2D3, Transformer Explainer.
- **For more technical audiences:** the Distill articles and Transformer Circuits.
